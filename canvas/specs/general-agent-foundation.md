# 通用 Agent 底座行为规格

首期范围：可信内部、自托管 OpenHands、单 Agent Server、本地 SQLite、人工恢复。ID 不重编号；废弃规格保留并加删除线。

| ID | 行为与验收 |
| --- | --- |
| GAF-001 | 包 ID/智能体 ID 命名空间；校验失败不切换版本；版本资源不可变；完整替换 prompt；仅显式工具/Skills/MCP，无全局记忆或插件串入；主/子/恢复共用解析器；有效配置可查看；禁用/卸载禁止新任务并保留历史。 |
| GAF-002 | 单一持久任务 owner；稳定请求键去重；一层许可委派，最多四个并行；独立工作目录与真实 SDK 会话；停止传播、诚实状态；重启人工恢复，未知写结果阻止自动重放；恢复校验原配置和工具兼容性。 |
| GAF-003 | Python/MCP 统一服务端策略；审批绑定调用 ID、参数和版本；子任务审批可在主会话处理；批准/拒绝/重复决定/刷新/重启保持一致；未经批准不执行；超时及取消不伪造外部撤销。 |
| GAF-004 | 上传/发布/读取/下载统一 ArtifactRef；明确任务授权，不暴露任意路径；主子任务仅通过成果引用传递文件；元数据和文件在刷新、重启后保留。 |
| GAF-005 | Local 应用使用通用主页、历史与会话；保留原生消息/工具事件；coding 页签不再作为应用入口；历史未通过兼容检查时只读；公共库和 Cloud 兼容路径保留。 |
| AF-UI-001 | 显式选择可用业务智能体；启动幂等重试；切换后端清空草稿，旧请求结果不能导航新后端。 |
| AF-UI-002 | 包源变更使旧校验失效；先校验再安装；显式启用与卸载；错误状态禁用依赖该状态的动作。 |
| AF-UI-003 | 持久任务状态快照驱动控件；对具体审批做决定；上传后重新读取服务端成果；停止等待执行真实结束；无管理任务的旧会话不提供运行控件。 |
| GAF-006 | 结果渲染器按包/工具/结构版本精确匹配；作用域重复报错；仅启用扩展执行；缺失/禁用/失败均保留文本、JSON、成果回退；宿主方法绑定后端，不暴露模型凭据。 |

后端代码及测试位于相邻 `software-agent-sdk` 仓库。验收替换模型提供方，保留真实配置解析、SDK 会话、工具执行、任务服务及 REST 通路；输出检查结构和成果内容，不要求回答文字完全一致。
